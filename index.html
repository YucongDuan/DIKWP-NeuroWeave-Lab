Run the full laboratory.

Download and extract the release, open a terminal in its project folder and use Python 3.11 or later. No API key or package installation is required.

Open http://127.0.0.1:8765 after starting the server.

Read the complete quick start →
python -m neuroweave list
python -m neuroweave run chapter-10 --out outputs/my-lab
python -m neuroweave serve --port 8765
